# ESP32-C6 + BNO085 + IM315TRX 姿勢データ無線送信

Seeed Studio XIAO ESP32-C6でBNO085の姿勢（クォータニオン）を読み取り、IM315TRX無線モジュールで送信するArduinoファームウェアです。PCで姿勢を3D表示するPythonスクリプトも含みます。

```text
BNO085 --I2C--> XIAO ESP32-C6 --UART--> IM315TRX ))) 315 MHz ))) 受信側 IM315TRX
                     |
                     +--USBシリアル--> PC（Pythonで3D表示）
```

- BNO085のGame Rotation Vector（地磁気を使わない姿勢）を50 Hzで取得します。
- 最新のクォータニオンを8バイトに圧縮し、IM315TRXの`TXDT`コマンドで10 Hzで送信します。
- 同じデータをUSBシリアルにも出力するため、無線なしでも姿勢をPCで確認できます。

## 配線

すべての機器のGNDを共通にしてください。

### BNO085（I2C）

| BNO085 | XIAO ESP32-C6 |
|---|---|
| VIN | 3V3 |
| GND | GND |
| SDA | D4 / GPIO22 |
| SCL | D5 / GPIO23 |

INT、RST、CSは接続しません。I2Cアドレスは`0x4A`を使います。基板側でアドレスを変えている場合は、スケッチの`BNO_I2C_ADDRESS`を合わせてください。

### IM315TRX（UART）

| IM315TRX | ピン番号 | 接続先 | 備考 |
|---|---:|---|---|
| VCC | 23 | 3V3 | **5 Vには接続しない**（動作電圧 2.0～3.6 V） |
| GND | 24 | GND | |
| RxD | 6 | D6 / GPIO16（TX） | TXとRXを交差させる |
| TxD | 7 | D7 / GPIO17（RX） | TXとRXを交差させる |
| BUSY | 1 | オープン | ESP32には接続しない |
| RESET | 25 | オープン | ESP32には接続しない |
| MODE1 | 17 | オープン | 内部プルアップでHIGH |
| MODE2 | 18 | GND | LOW |
| MODE3 | 19 | GND | LOW |
| REG | 22 | オープン | 内部プルアップでHIGH |
| NC | 26 | オープン | 必ず未接続 |

MODE1 = H、MODE2 = L、MODE3 = L、REG = Hの組み合わせで、IM315TRXが**データモード**で起動します。モードはハードウェアで固定しているので、ソフトウェアからは制御しません。

### 配線まとめ

```text
                    XIAO ESP32-C6
                   +----------------+
BNO085 SDA --------| D4 / GPIO22    |
BNO085 SCL --------| D5 / GPIO23    |
                   |                |
IM315TRX RxD <-----| D6 / GPIO16 TX |
IM315TRX TxD ----->| D7 / GPIO17 RX |
                   |                |
BNO085 VIN --------| 3V3            |
IM315TRX VCC ------| 3V3            |
BNO085 GND --------| GND            |
IM315TRX GND ------| GND            |
                   +----------------+
```

> [!WARNING]
> **はんだブリッジに注意してください。**
> MODE1～MODE3（17～19番ピン）は隣り合っています。実機で17番と19番がはんだでつながり、MODE1がLOWになってデータモードで起動しなかったことがあります。この状態では、UARTのコマンドには応答するのに無線の送受信ができません。
>
> はんだ付けの後は、電源を入れる前にテスターで次を確認してください。
> - 隣り合うピン同士、特に17～19番と22～26番の間に導通がないこと
> - 18番と19番以外のピンがGNDと導通していないこと
> - 通電時にMODE1とREGがHIGH、MODE2とMODE3がLOWであること

## 使い方

### 1. Arduino IDEを準備する

1. ボードマネージャーからESP32用ボードパッケージ（Espressif）をインストールします。
2. ボードとして`XIAO_ESP32C6`を選択します。
3. ライブラリマネージャーから`Adafruit BNO08x`をインストールします。

### 2. IM315TRXの通信設定を確認する

スケッチは、IM315TRXのUARTを**19200 bps、8N1**とみなして通信します。モジュールの設定が違う場合は、スケッチ冒頭の定数を変更してください。

```cpp
constexpr uint32_t IM315_BAUD = 19200;
```

IM315TRX Ver.01.07で、この設定と`TXDT`による送信が動作することを確認しています。

### 3. ファームウェアを書き込む

1. Arduino IDEで`BNO085_NoMag_IM315TRX/BNO085_NoMag_IM315TRX.ino`を開きます。
2. XIAO ESP32-C6のCOMポートを選び、書き込みます。
3. シリアルモニタを**115200 bps**で開きます。何も表示されない場合は、XIAOのRESETボタンを押します。

正常に動作していれば、次のように表示されます。

```text
READY
Q,0.999998,0.000056,0.000090,0.002016
TX:4000000100010021
IM315:OK
```

| 出力 | 意味 |
|---|---|
| `READY` | BNO085の初期化に成功 |
| `Q,w,x,y,z` | クォータニオン（50 Hz）。Pythonスクリプトがこの行を読みます |
| `TX:<16進16文字>` | IM315TRXへ送信したペイロード（10 Hz） |
| `IM315:OK` / `IM315:NG` | IM315TRXが送信コマンドを受理した／拒否した |
| `ERROR:...` | エラー。[トラブルシューティング](#トラブルシューティング)を参照 |

### 4. 姿勢をPCで3D表示する

必要なパッケージをインストールします。

```powershell
py -m pip install pyserial vpython scipy
```

[`python/BNO085_NoMag.py`](python/BNO085_NoMag.py)の先頭にあるCOMポートを、XIAO ESP32-C6のポートに合わせて変更します。

```python
COM_PORT = "COM3"   # デバイスマネージャーやArduino IDEで確認したポート
BAUD_RATE = 115200
```

**Arduino IDEのシリアルモニタを閉じてから**、リポジトリのルートで実行します。同じCOMポートは2つのソフトから同時に開けません。

```powershell
py .\python\BNO085_NoMag.py
```

`py`コマンドがない環境では`python`に置き換えてください。

ブラウザまたはウィンドウに直方体が表示され、BNO085の傾きに合わせて回転します。

- 起動時の姿勢が基準になります。`R`キーを押すと、その時点の姿勢を新しい基準にします。
- 矢印はIMUの軸で、赤がX、緑がY、青がZです。
- 終了するには、ターミナルで`Ctrl+C`を押します。

## 仕様

### タイミング

| 処理 | 周期 |
|---|---|
| BNO085のGame Rotation Vector取得 | 50 Hz（20 ms） |
| IM315TRXへの無線送信 | 10 Hz（100 ms）。送るのは最新のクォータニオン |
| IM315TRXの応答待ちタイムアウト | 500 ms |

### 無線ペイロード

IM315TRXへは次のコマンドを送ります（終端はCRLF）。

```text
TXDT <16進16文字>
```

16文字（8バイト）の中身は次のとおりです。

```text
w上位, w下位, x上位, x下位, y上位, y下位, z上位, z下位
```

- 各成分は**符号付き16ビットのQ14形式**（`値 × 16384`を整数に丸めたもの）で、上位バイトが先です。
- 分解能は約0.000061、範囲は-1～+1です。
- `q`と`-q`は同じ回転を表すため、送信前に`w ≥ 0`となるよう符号をそろえます。
- 無効なクォータニオン（非有限値、ノルムが1から大きく外れた値）は送信しません。

### BUSYとRESETの扱い

このファームウェアは、IM315TRXのBUSY・RESETを使いません。

- BUSYの状態は確認せず、送信間隔ごとに必ず送信します。
- 前回の応答（`OK`/`NG`）が届いていなくても次を送り、届かなかった分は`ERROR:IM315_REPLY_TIMEOUT`として報告します。
- BUSYがHIGHの間に送ったコマンドはIM315TRXに無視されるため、一部の送信が失われることがあります。その場合も、次の周期で最新の姿勢が送られます。

## 受信側で無線データを確認する

受信側IM315TRXをIM920-USB2経由でPCにつなぎ、315 MHz区間の通信を確認する手順です。受信側のIM315TRXにはプログラムを書き込まず、Tera Termからコマンドで設定します。

> 以下は、送信側・受信側ともにIM315TRX Ver.01.07で確認した手順です。

### 1. PCに接続する

1. 受信側IM315TRXをIM920-USB2に載せ、USBケーブルでPCに接続します。
2. デバイスマネージャーの「ポート（COMとLPT）」に、CP2102NのCOMポートが表示されることを確認します。表示されない場合は、Silicon LabsのCP210xドライバをインストールします。
3. 受信側もデータモード（MODE1 H、MODE2 L、MODE3 L、REG H）で動かします。IM920-USB2でのMODE端子の扱いは、IM920-USB2の取扱説明書（回路図）を確認してください。

### 2. Tera Termを設定する

「新しい接続」で「シリアル」を選び、上で確認したCOMポートを指定します。「設定」→「シリアルポート」を次のようにします。

```text
スピード:   19200
データ:     8 bit
パリティ:   none
ストップ:   1 bit
フロー制御: none
送信遅延:   10 ミリ秒/字、100 ミリ秒/行
```

「設定」→「端末」で、送信する改行コードを「CR+LF」にし、「ローカルエコー」にチェックを入れます。

> [!TIP]
> - Tera Termは入力した文字を1文字ずつ送ります。打ち間違えたらBackspaceで直さずにEnterを押し、もう一度打ち直してください（崩れた文字列には`NG`が返ります）。
> - 1行ずつ入力し、応答を確認してから次の行に進んでください。不揮発メモリへの書込み中はBUSYがHIGHになり、その間に届いた文字は無視されます。

### 3. モジュールの情報を確認する

送信側・受信側それぞれで次のコマンドを実行します。送信側のIDは次の手順で使うので控えておきます。

| コマンド | 内容 | 応答例 |
|---|---|---|
| `RDID` | 固有IDの読出し | `A51F` |
| `RDVR` | 製品バージョンの読出し | `IM315TRx Ver.01.07` |
| `RDCH` | 無線チャンネルの読出し | `20` |

`RDCH`に`NG`が返る場合は、送信側・受信側の両方で次を実行し、チャンネルを出荷時の値の20にそろえます。

```text
ENWR
STCH 20
DSWR
```

### 4. 送信側のIDを受信側に登録する

受信側IM315TRXは、登録された送信モジュールのデータだけを出力します。受信側で次を1行ずつ実行します。`A51F`は、送信側で`RDID`を実行して得た値に置き換えてください。

```text
ENWR
SRID A51F
RRID
DSWR
```

| 送った行 | 正常な応答 | 異常時の意味 |
|---|---|---|
| `ENWR` | `OK` | 応答がない場合、コマンドが届いていない |
| `SRID A51F` | `OK` | `NG`の場合、書込み許可が有効になっていない |
| `RRID` | `A51F` | 空行の場合、登録されていない |
| `DSWR` | `OK` | - |

`ENWR`で出した書込み許可は、電源を切るかUSBを抜き差しすると無効に戻ります。`SRID`の直前に、同じ接続のまま`ENWR`を送ってください。登録したIDは電源を切っても保持されます。

### 5. 受信データを確認する

送信側のXIAO ESP32-C6を動かすと、受信側のTera Termに次のような行が約10 Hzで表示されます（実機の出力例）。

```text
00,A51F,C9:36,9E,01,DD,FC,5F,21,1C
00,A51F,CA:36,9E,01,E6,FC,5E,21,1B
00,A51F,CC:36,9F,01,EE,FC,5F,21,1A
```

行の形式は`aa,bbbb,cc:d1,d2,...,d8`です（IM315シリーズ取扱説明書 ソフトウェア編 7-2項）。

| 部分 | 意味 |
|---|---|
| `aa` | 送信側のノード番号 |
| `bbbb` | 送信側の固有ID |
| `cc` | 受信信号強度（RSSI） |
| `d1`～`d8` | ユーザデータ8バイト（カンマ区切りの16進） |

コロンより後ろのカンマを取り除くと、送信側が`TXDT`で送った16文字のペイロードと同じになります。

### 6. ペイロードをクォータニオンに戻す

2バイトずつ符号付き16ビット整数として読み、16384で割ります。上の1行目の場合は次のようになります。

| 成分 | 16進 | 符号付き整数 | 値 |
|---|---|---:|---:|
| w | `369E` | 13982 | 0.8534 |
| x | `01DD` | 477 | 0.0291 |
| y | `FC5F` | -929 | -0.0567 |
| z | `211C` | 8476 | 0.5173 |

ノルムがほぼ1.000になっていれば、正しく受信できています。

Pythonで変換する例:

```python
import struct

def decode_line(line: str):
    """受信行 'aa,bbbb,cc:d1,...,d8' からクォータニオン (w, x, y, z) を返す。"""
    data = bytes.fromhex(line.split(":", 1)[1].replace(",", ""))
    return tuple(v / 16384.0 for v in struct.unpack(">4h", data))

print(decode_line("00,A51F,C9:36,9E,01,DD,FC,5F,21,1C"))
# (0.8533935546875, 0.02911376953125, -0.05670166015625, 0.517333984375)
```

> [!NOTE]
> 同梱の[`python/BNO085_NoMag.py`](python/BNO085_NoMag.py)は、XIAO ESP32-C6のUSBシリアルから`Q,w,x,y,z`形式の行を読みます。受信側IM315TRXのデータを3D表示するには、上のような変換処理を加える必要があります。

## トラブルシューティング

### シリアルモニタのエラー表示

| 表示 | 確認すること |
|---|---|
| `ERROR:BNO085_NOT_FOUND` | BNO085の電源、SDA/SCLの配線、I2Cアドレス（`0x4A`） |
| `ERROR:REPORT_START_FAILED` / `ERROR:REPORT_RESTART_FAILED` | BNO085とのI2C通信、ライブラリのインストール |
| `ERROR:INVALID_QUATERNION` | BNO085の接続状態 |
| `ERROR:IM315_TX_REJECTED` | IM315TRXのモード、コマンド形式 |
| `ERROR:IM315_REPLY_TIMEOUT` | ボーレート、TX/RXの交差配線、IM315TRXの電源。BUSY中に送ったコマンドが無視されたときにも表示される |
| `ERROR:IM315_LINE_TOO_LONG` | ボーレートの不一致などで、IM315TRXからの応答が正しく読めていない |

### その他の症状

| 症状 | 確認すること |
|---|---|
| UARTの応答はあるが無線で送受信できない | MODE1～MODE3、REGのはんだブリッジ（[配線](#配線)の警告を参照） |
| 受信側に何も表示されない | 受信側への送信側IDの登録、チャンネルの一致、送信側で`IM315:OK`が出ているか |
| Tera Termで`RDCH`が`NG` | 打ち直しても`NG`なら、`ENWR` → `STCH 20` → `DSWR`でチャンネルを20にそろえる |
| Tera Termで`RRID`が空行 | IDが登録されていない。1行ずつ応答を確認しながら`ENWR` → `SRID`をやり直す |
| Pythonスクリプトでポートを開けない | Arduino IDEのシリアルモニタを閉じる。`COM_PORT`の番号を確認する |
